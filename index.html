Tentang Saya

Profil

Saya Rochmad Djojo Oktabianto (Jojo) — mahasiswa D4 Teknik Informatika di Politeknik Elektronika Negeri Surabaya (PENS), dengan latar belakang Teknik Komputer & Jaringan dari SMK Negeri Gudo, Kabupaten Jombang.

Keahlian saya di bidang IT Network System Administration (ITNSA) telah diuji di tiga panggung kompetisi bergengsi pada tahun 2026 — mulai dari tingkat kabupaten hingga provinsi, dengan standar WorldSkills Competition.

Saya terbiasa merancang, mengonfigurasi, dan mengamankan infrastruktur jaringan dan server berskala enterprise di bawah batas waktu ketat: Linux Debian Server, Windows Server Active Directory, routing dinamis OSPF/BGP, hingga network troubleshooting menggunakan Wireshark.
